# База знаний для технических писателей

Статический сайт, экспортированный из Tilda и подготовленный для GitHub Pages.

## Публикация

1. Загрузите содержимое этой папки в корень репозитория (вместе со скрытым файлом `.nojekyll`).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.

GitHub Pages сам отдаёт `techwriterbooks.html` по адресу `/techwriterbooks`, поэтому `.htaccess` не нужен.

## Собственный домен

Чтобы сайт открывался по адресу techwritersbase.online, укажите домен в Settings → Pages → Custom domain
(GitHub создаст файл `CNAME`) и настройте DNS у регистратора по инструкции GitHub.
